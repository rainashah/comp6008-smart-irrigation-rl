# comp6008-smart-irrigation-rl
RL-based continuous irrigation controller using DDPG, TD3, and SAC. Optimizes water use while maintaining soil-water levels using SILO climate and CSIRO soil data.

## Data audit

[Read the climate and soil audit findings](docs/DATA_AUDIT.md), including the comparison of Kyabram and Kununurra Aero and the remaining field-selection checks.

[Download the complete audit package](data/Irrigation_Data_Audit.zip) for raw data, detailed results and reproducible scripts.

Current status: data screening completed; final field location, shared environment settings and agent implementations remain to be finalised.
